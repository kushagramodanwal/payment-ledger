# Single Currency (INR) Migration - Complete ✅

## What Changed

### Backend Changes

1. **Wallet Model (`app/models/wallet.py`)**
   - ❌ Removed `currency` column
   - ✅ Added `name` column (user-customizable wallet name)
   - ✅ One wallet per user (unique constraint on `user_id`)

2. **Transaction Model (`app/models/transaction.py`)**
   - ❌ Removed multi-currency fields: `source_currency`, `target_currency`, `source_amount`, `target_amount`
   - ❌ Removed FX fields: `fx_rate`, `fx_provider`, `fx_timestamp`
   - ✅ Single `amount` field (INR only)
   - ✅ Kept idempotency, status, timestamps

3. **Services**
   - ❌ Deleted `fx_service.py` entirely
   - ✅ Simplified `transaction_service.py` - no FX conversion
   - ✅ Updated `auth_service.py` - auto-create wallet on signup with personalized name

4. **Repositories**
   - ✅ Simplified `wallet_repo.py` - removed currency parameters
   - ✅ Added `update_wallet_name()` function
   - ✅ Simplified `transaction_repo.py` - single wallet per user

5. **API Endpoints**
   - **Wallet:** `/wallet` (singular) - GET wallet, PATCH /wallet/name
   - **Transactions:** `/transactions/transfer` - no currency params needed
   - ✅ All endpoints now single currency (INR)

6. **Database Migration**
   - ✅ Created `003_single_currency_system.py`
   - ✅ Dropped old tables, created new simplified schema
   - ✅ Migration ran successfully

### Frontend Changes

1. **API Layer (`api/api.js`)**
   - ❌ Removed `createWallet(currency)` and `getWallets()`
   - ✅ Simplified to `getWallet()` - returns single wallet
   - ✅ Added `updateWalletName(name)` - user can customize wallet name
   - ✅ `transferMoney(receiverId, amount)` - no currency params

2. **Components**
   - **Dashboard.jsx**: Simplified, shows single wallet with ₹ symbol
   - **TransferModal.jsx**: Removed currency dropdowns, shows ₹ only
   - **TransactionHistory.jsx**: Shows ₹ symbol, simpler layout

3. **Removed Features**

   - ❌ FX conversion preview
   - ❌ Currency symbols map (except ₹)

## Database Schema (After Migration)

### Users Table (Unchanged)
```sql
id              INT PRIMARY KEY
name            VARCHAR
email           VARCHAR UNIQUE
password_hash   VARCHAR
created_at      TIMESTAMP
```

### Wallets Table (NEW)
```sql
id          INT PRIMARY KEY
user_id     INT UNIQUE  -- One wallet per user
name        VARCHAR(100) DEFAULT 'My Wallet'
balance     NUMERIC(10,2) DEFAULT 0.00
created_at  TIMESTAMP
updated_at  TIMESTAMP
```

### Transactions Table (SIMPLIFIED)
```sql
id                  INT PRIMARY KEY
idempotency_key     VARCHAR UNIQUE
sender_wallet_id    INT
receiver_wallet_id  INT
amount              NUMERIC(10,2)  -- Single amount in INR
status              VARCHAR(20)
created_at          TIMESTAMP
```

## API Endpoints

### Authentication
- `POST /auth/signup` - Create user + auto-create wallet
- `POST /auth/login` - Get JWT token

### Wallet
- `GET /wallet` - Get user's wallet (balance + name)
- `PATCH /wallet/name` - Update wallet name

### Transactions
- `POST /transactions/transfer` - Send money (INR only)
  - Body: `{ receiver_user_id, amount }`
  - Header: `Idempotency-Key` (auto-generated by frontend)
- `GET /transactions` - Transaction history with pagination
